# CONSPACE ROOMS: helping words

Shortcuts for testing the walk, in any keyboard layout.

| Keys | Within | What happens |
|---|---|---|
| `M` × 5 | 2.5 s | Chevrons on the floor lead to the next portal. Again: they go out. In the light: the ending plays. |
| `P` × 5 | 2.5 s | Testers’ tour: a glowing line and a run through every work and portal to the end. Again: it stops. |
| `1` × 5 | 3 s | Fear (the hospital) |
| `2` × 5 | 3 s | Memory (grandmother’s rooms) |
| `3` × 5 | 3 s | Acceptance (the light) |
| `0` × 5 | 3 s | Acceptance and the finale |
| `Q`, held 1 s | | The walk ends with the final card |
| `R` × 3 | 1.2 s | Bug report: the current frame with the state of the walk written over it, also saved as a file |
| `F` | | Fullscreen |

URL parameters: `?seed=N` rebuilds the same labyrinth, `?tier=0` to `3` sets the quality, `?lang=ru` or `en` picks the language.

## Reporting a bug

Press `R` three times quickly. Take a screenshot of the picture that comes up, or keep the saved file, and send it with one line: what you expected and what happened. On a phone, a plain screenshot with the minutes walked and the works seen does the same.
